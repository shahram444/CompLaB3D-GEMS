# CompLB3D model manifest
#
# One row per known genome-scale model. The solver uses this to
#   * find a bundled or cached copy before ever touching the network,
#   * verify that the file it found is the file it expected, and
#   * warn when a model is a DIFFERENT REVISION than the case was built against.
#
# That last check is the important one. <exchange_reaction_indices> in CompLaB.xml
# is POSITIONAL: if a revision inserts one reaction, every index after it silently
# points somewhere else and the run does not complain. Naming exchanges instead,
# with <exchange_reaction_names>, makes that impossible rather than merely visible.
#
# Two pairs of counts, because they answer different questions:
#   raw_species / raw_reactions   how many <species  and <reaction  tags are in the
#                                 file. A cheap check before parsing.
#   met / rxn                     how many the parsed MODEL has. Smaller than the raw
#                                 counts, because boundaryCondition species are tags
#                                 but are not metabolites. The exact check.
#
# hash and bytes are of the UNPACKED xml, so a bundled .xml.gz and a downloaded .xml
# give the same values. Set any field to 0 to skip that check.
#
